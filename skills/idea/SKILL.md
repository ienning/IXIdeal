# Idea to Project Skill

## 触发方式

- `/idea` — 从零开始，进入 Phase A 对话引导，AI 自动创建模板文件
- `/idea <文件路径>` — 读取已有模板，智能路由

## 行为准则

- 每次只问一个问题，等待用户回答后再继续
- 语气友好，为每个字段提供简短的填写示例
- 用户每回答一个字段，立即用 Edit 工具写入模板文件（支持中断续写）
- Phase B 搜索时并行执行 GitHub 和 Web 搜索（同一消息中调用两次 WebSearch）
- 分析结果写入模板文件 `<!-- ANALYSIS_START -->` 和 `<!-- ANALYSIS_END -->` 之间的内容

---

## 启动路由逻辑

收到指令后，执行以下判断：

```
1. 是否传入了文件路径？
   ├─ 是：用 Read 工具读取文件，统计 8 个字段中有实质内容（非空行、非仅有 `-`）的数量
   │     ├─ ≥6 个字段有内容 → 告知用户"信息充分，直接开始分析" → Phase B
   │     └─ <6 个字段有内容 → 告知用户"我来帮你补全空字段" → Phase A（仅问空字段）
   └─ 否：告知用户将创建新模板文件，路径为 idea-YYYY-MM-DD.md → 用 Write 工具创建 → Phase A
```

新建模板时，从 `idea-template.md`（如存在）复制结构；否则使用内置空白结构（8 个字段 + 分析占位区）。

---

## Phase A：对话引导

按以下顺序逐一引导，每次只问一个字段，等用户回答后再继续：

**字段 1 — 核心想法**
> "先从最重要的开始——用一两句话告诉我你想做什么？不需要很完整，有个大概方向就行。"
> （示例：我想做一个帮助独立开发者自动记录工作时间的命令行工具）

**字段 2 — 目标用户**
> "这个产品主要给谁用？能描述一下他们是什么样的人吗？"
> （示例：独立开发者、自由职业者，同时有多个项目，希望了解时间分配）

**字段 3 — 核心价值**
> "它能帮用户解决什么具体问题？或者带来什么好处？"
> （示例：现有工具要么太复杂，要么无法自动识别工作内容）

**字段 4 — 期望功能**
> "你希望它有哪些功能？想到什么说什么，不需要完整的列表。"
> （示例：自动识别当前项目、手动打标签、每周生成摘要报告）

**字段 5 — 技术偏好**
> "你有技术背景吗？倾向用什么语言或框架？还是完全不了解技术，希望 AI 来决定？"
> （示例：熟悉 Python，希望是命令行工具；或：完全不懂技术）

**字段 6 — 资源约束**
> "你大概有多少时间、预算和人手？"
> （示例：个人项目，业余时间，每周约 10 小时，无预算）

**字段 7 — 成功标准**
> "你心目中第一个里程碑是什么？做到什么程度算'成功了'？"
> （示例：能在自己的电脑上稳定运行一个月，并生成满意的周报）

**字段 8 — 竞品参考**
> "市场上有没有类似的产品？你用过哪些，喜欢或不喜欢哪些地方？"
> （示例：用过 Toggl，喜欢报表，但不喜欢手动开始/停止计时）

### 写入规则

用户回答每个字段后：
1. 用 Edit 工具将回答写入模板文件对应字段的 `>` 引用块内（替换空行内容）
2. 简短确认（一句话），然后继续下一个字段
3. 所有字段完成后，说"好，信息收集完毕，开始分析。" → 进入 Phase B

## Phase B：深度分析

### Step 1：提取关键词

从模板内容中提取：
- 产品类型关键词（用于 GitHub 搜索，英文）
- 行业/领域关键词（用于 Web 竞品搜索）
- 技术栈关键词

### Step 2：并行搜索

**在同一消息中同时调用两次 WebSearch（不要顺序等待）：**

搜索 A（GitHub 方向）：
```
site:github.com <产品类型英文关键词> <技术栈关键词>
```

搜索 B（竞品方向）：
```
<产品类型> 竞品 alternatives 2024
```

评估 GitHub 搜索结果时关注：star 数量、最近提交时间（活跃度）、许可证类型、README 描述匹配度。

### Step 3：追问（如有必要）

如果分析过程中发现关键信息不清晰（特别是技术实现细节或目标市场），向用户提出最多 2 个具体问题，等待回答后继续。

### Step 4：生成并写入分析结果

生成以下格式的分析内容，用 Edit 工具替换模板文件中 `<!-- ANALYSIS_START -->` 到 `<!-- ANALYSIS_END -->` 之间的全部内容：
